# iCoffee growth launch playbook

## Search Console
- Verify `icoffeex.com` as a Domain property using DNS TXT (this covers the `www` host too).
- Submit `https://www.icoffeex.com/sitemap.xml`.
- Request indexing for the homepage, Black, Creamer, Ingredients, Science and Authority pages.
- Review Page Indexing, Core Web Vitals and Search performance weekly.

## Analytics
- Replace `G-XXXXXXXXXX` in `js/analytics.js` with the real GA4 Measurement ID.
- Test `view_item`, `select_item`, `store_click`, `learn_more` and `review_submit`.
- Mark `store_click` as a key event in GA4 if the store visit is your primary conversion.

## Authority / backlinks
The website cannot create third-party backlinks by itself. Use the new Authority page as a canonical source and pitch it to relevant publishers, partners, retailers and genuine PR contacts. Never buy bulk spam links or create fake mentions.

Suggested outreach assets:
- Official brand description
- Product fact sheet
- Ingredient/Science references
- High-resolution product images
- Official store link
- Company/contact details

## Content publishing
The journal section has been removed from this build.


## Conversion optimization
Primary funnel: Homepage → Product page → Official Store.
Secondary funnel: Educational article → Product page → Official Store.
Test one CTA at a time and compare store-click rate by page and product. Keep the store link clearly visible without aggressive popups.

## Backlink quality checklist
Prefer relevant, real sites with editorial value. A few strong mentions are more useful than a large volume of low-quality directory links. Keep anchor text natural and brand-led.
